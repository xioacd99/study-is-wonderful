# Resource-source marks

The maintainer confirmed permission to use the universities' and companies' marks on 2026-11-16 and confirmed permission for the fourteen added source marks on 2026-11-21. These identify the sources of the linked learning resources; they do not imply sponsorship or endorsement. Trademark ownership remains with the respective organizations. This record is not a general license for downstream trademark use.

`sources.json` records the original asset URL, file hash, display name and family order. The university seals replace the previous text-only placeholder badges. Their exact SVG artwork was retrieved from the cited Wikimedia file pages and cross-checked against the institutions' identities:

- [MIT brand guide](https://brand.mit.edu/logos-marks/mit-seal)

- [Stony Brook identity history](https://www.stonybrook.edu/commcms/libspecial/archives/logos)

Company marks retain their existing official website or official GitHub organization sources. Existing Bilibili and YouTube SVG assets are retained. Google and Clay assets are decoded to PNG solely for SVG renderer compatibility, without resizing, cropping or recoloring.

## Maintenance

Run `python tools/build_resource_map.py`, then `python tools/build_resource_map.py --check` and `python -m unittest discover -s tests -v`.

The generator derives the wall from primary and additional catalog links in both READMEs, including sources only credited in text. Register each new hostname with its actual source. For a hosted article that explicitly credits a separate publisher, use a reviewed host/path rule (e.g. ggml-org on Hugging Face), not a guess based on the title. Unclassified links fail the build. It embeds the original files into three stacked source cards in this order: `source-wall-universities.svg`, `source-wall-projects.svg`, and `source-wall-companies.svg`. Each card uses six equal-width columns, preserves each mark's aspect ratio, and keeps brand families together. Both READMEs share the same artwork and use localized headings and alternative text. No external asset request is needed to render the wall. SVG artwork added on November 21 is proportionally rasterized for consistent inline rendering; the registry also records the unmodified upstream file hash. Register verified marks with their provenance and hash. Each displayed source requires an authentic, authorized logo. If the provenance or permission is unresolved, hold the affected catalog addition and report it; the builder rejects text placeholders. Display names are retained as accessible labels alongside real marks. For verified course producers whose recordings are linked through a third-party platform, record the course ID, exact resource URL, and attribution evidence in `course_credits`; an unrelated link change invalidates that attribution until reviewed. Source credit is not a claim that the linked recording matches a particular official edition. Unused sources are not displayed. The README uses an accessible descriptive alt string; SVG title/description and visible names identify individual marks.

All marks must declare an `organization` and an explicit `group` (`university`, `project`, or `company`) in `sources.json`. Use `university` for higher-education institutions and their programs; the `project` group includes independent projects, platforms, and nonprofit research sources such as Ai2; use `company` for company and business brands. Use the same organization key for related brands even when they belong in different cards (for example, Google and YouTube). Within each card the generator groups each organization contiguously. Organization groups sort by `organization_names` alphabetically (case-insensitive); sources within each group sort by display name alphabetically.
